# 数据统计助手（six-tj-web）

一款**纯本地运行**的数据记录与分析工具，所有数据保存在本机，无需网络即可使用全部核心功能。帮助用户高效完成报单记录、数据核对与统计分析。

## 核心功能

- **智能报单解析**：粘贴文本自动识别玩法、号码与金额，支持多种金额标记与单位，解析结果即时预览
- **自动结算核对**：报单保存后自动结算，多玩法匹配判定与派发计算，结果一目了然
- **数据统计报表**：按类型、客户、期号多维度汇总，支持导出
- **数据参考**：基于历史数据的频率参考与 AI 参考（AI 参考需自行配置 API Key）
- **客户与账单管理**：客户档案、往来账单、系数个性化设置

## 技术栈

- [UniApp](https://uniapp.dcloud.net.cn/)（Vue 3）+ Vite
- 本地存储方案，全流程离线可用
- 支持 H5 与 Android 等多端打包（HBuilder X）

## 快速开始

```bash
# 安装依赖
npm install

# H5 本地开发
npm run dev:h5

# H5 构建
npm run build:h5
```

Android 等原生端打包请使用 HBuilder X 导入本项目后操作。

## 目录结构

```
├── src/
│   ├── engine/        # 本地引擎（解析、结算、存储、AI 参考）
│   ├── components/    # 通用组件
│   ├── pages/         # 页面
│   └── common/        # 共用工具
├── admin-portal/      # 管理端（独立部署）
└── package.json
```
